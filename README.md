# Financeiro

App pessoal nativo para iPhone, com prioridade em privacidade e funcionamento local.

## Estado

Checkpoint inicial de desenvolvimento. Ainda não há versão instalada ou validada em iPhone.

## Escopo acordado

- Organizar receitas e despesas, estabelecimento, valor, data/hora, conta e categoria.
- Dados locais, sem servidor, anúncios, analytics ou agregador bancário.
- Backup criptografado exportável para o iCloud Drive do usuário.
- Integração local com Atalhos para transações Apple Pay compatíveis.

## Limites da plataforma

Um app iOS comum não tem acesso geral às notificações de outros apps. FinanceKit não oferece suporte geral a bancos brasileiros. A automação de transação do Atalhos cobre eventos compatíveis e exige configuração no iPhone. Não equivale a um extrato completo.

## Continuidade

O desenvolvimento será entregue em branch e pull request, com decisões, testes e pendências documentados. Não colocar extratos, dados reais, chaves, certificados ou senhas neste repositório.
