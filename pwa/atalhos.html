Voltar para o app

Do iPhone para o seu cofre.

Use Atalhos para preparar registros. Você revisa os dados no Financeiro antes de salvar. O aplicativo não lê notificações bancárias por conta própria.

1. Instale primeiro

  1. Abra o endereço no Safari. Se a hospedagem pedir, entre com a conta que tem acesso ao app.
  2. Toque em Compartilhar, depois Adicionar à Tela de Início. Ative Abrir como App da Web, se essa opção aparecer.
  3. Abra pelo novo ícone e crie o cofre com uma senha de pelo menos 12 caracteres.

O Safari e o aplicativo instalado podem ter armazenamentos separados. Use sempre o ícone instalado para seus lançamentos. Para migrar dados entre eles, exporte e restaure um backup. Apagar o app ou os dados do site pode apagar o cofre local.

2. Faça um teste fictício

No Financeiro instalado, vá a Registros → Receber dados e cole o exemplo abaixo. Confira a prévia e confirme apenas se estiver tudo certo.

{
  "amount": "1,23",
  "merchant": "Loja de teste",
  "kind": "expense",
  "account": "Cartão de teste",
  "category": "Teste",
  "id": "29e3bfd2-740d-4b72-a6b7-171a58354529"
}

Repita o mesmo teste: o UUID identifica o mesmo registro e impede uma segunda inserção. Depois exclua o lançamento fictício. Sem UUID, cada importação pode criar um novo registro.

3. Monte o Atalho

  1. No Atalhos da Apple, crie um atalho com uma ação Dicionário e os campos do exemplo: amount, merchant, kind, account, category e id.
  2. Use um valor positivo no formato brasileiro, como 123,45. kind deve ser expense (despesa), income (receita) ou transfer (transferência).
  3. Para id, use um UUID único por transação. Reutilize esse mesmo UUID somente ao reenviar o mesmo evento. Um UUID fixo para todas as compras impediria novos registros.
  4. Converta o dicionário para texto JSON e use a ação Copiar para a Área de Transferência. Se sua versão não oferecer a conversão, comece com uma ação Texto contendo o JSON do exemplo e substitua os campos conscientemente.
  5. Abra o Financeiro pelo ícone instalado. Em Receber dados, cole, revise e confirme.

Se a origem informar a data original, acrescente date no formato 2026-10-31T12:30:00-03:00. Sem esse campo, o horário será o da importação, com uma observação avisando a diferença.

4. Automação da Carteira

Quando o seu iPhone oferecer o gatilho Transação/Carteira, escolha o cartão e associe os campos disponíveis ao dicionário. Verifique valor e estabelecimento no aparelho. Esse evento não é um extrato completo e pode não cobrir Pix, recebimentos, estornos ou pagamentos online.

Gatilhos de Notificação existem apenas em versões compatíveis do Atalhos. Antes de automatizar textos de banco, teste alertas recusados, recebidos e incompletos. Esta versão não adivinha valores nem tipos de operação de uma notificação arbitrária.

A PWA não recebe App Intents nativos e não importa silenciosamente enquanto está fechada. Evite dois gatilhos para a mesma compra. A área de transferência é temporária: depois de importar, copie outro conteúdo para removê-la.

5. Guarde uma cópia no iCloud

  1. Abra a aba Cofre e prepare um backup criptografado.
  2. Toque em Compartilhar e escolha Salvar em Arquivos → iCloud Drive. Se o compartilhamento não estiver disponível, baixe o arquivo e mova-o para o iCloud pelo app Arquivos.
  3. Aguarde a sincronização no Arquivos. O Financeiro sabe que preparou ou compartilhou o arquivo, mas não confirma a gravação final nem o upload.
  4. Guarde a senha do cofre fora do app. Ela também abre o backup, inclusive em outro dispositivo. A senha não pode ser recuperada pelo aplicativo.

Um Atalho pode receber o arquivo pela folha de compartilhamento e usar a ação Salvar Arquivo na pasta escolhida. Ainda exige uma interação para entregar o arquivo; não é sincronização contínua em segundo plano.

Privacidade

O site hospeda o código do aplicativo. Os lançamentos ficam criptografados no armazenamento local do navegador; o código do app não envia registros para servidores. Backups e cópias da área de transferência só saem quando você os compartilha. Não coloque dados financeiros em endereços de URL, chats, repositórios ou serviços de IA.

O projeto nativo foi preservado separadamente. Esta versão é uma PWA: offline após o primeiro carregamento completo, com backup por exportação e restauração por arquivo.
